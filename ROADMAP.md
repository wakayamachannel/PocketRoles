Notes
* Custom hat artwork at SNR scale cannot be drawn by the assistant; the mod provides the loader + a sample pack; art must come from packs whose authors allow reuse.
* Publishing needs the user's own GitHub account (the assistant cannot create accounts or handle credentials); the assistant prepares the repository content and release files and can push once the user has authenticated git on this PC.
* Friends' clients only see mod features if they install the mod (v0.5); with v0.1–v0.4 they are vanilla players.
