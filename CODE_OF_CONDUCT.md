# 行動規範（Code of Conduct）

[日本語](#日本語) | [English](#english) | [简体中文](#简体中文)

## 日本語

PocketRoles は、**[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)** を行動規範として使います。
全文（英語）はそのページにあります。日本語の訳（2.1）: <https://www.contributor-covenant.org/ja/version/2/1/code_of_conduct/>
下は、その短いまとめを自分たちの言葉で書いたものです。まとめと全文がちがうときは、全文に従います。
出典とライセンスは、いちばん下の Attribution にあります。

### どこで守るか

GitHub（Issue・Pull Request）、公式 Discord「PocketRoles 役職部屋」、サポートのメール、そして PocketRoles の名前で人と話すところ全部です。

### みんなで守ること

- 相手を大事にします。年・性別・国・言葉・見た目・ゲームのうまさなどで、人を下に見ません。
- ちがう意見も、落ち着いて聞きます。
- まちがえたら、あやまって直します。
- 自分だけでなく、みんなにとってよいことを考えます。

### してはいけないこと

- 悪口、からかい、差別、いやがらせ、しつこく追いかけること
- 性的な言葉や画像
- ほかの人の個人情報（本名・住所・フレンドコードなど）を、本人のゆるしなしに出すこと
- おどすこと、暴力をすすめること
- その場にふさわしくないふるまい

### 困ったときは

守られていないと思ったら、メールで知らせてください。

- あて先: `pocketroles.report+help@gmail.com`
- 件名: `[PocketRoles] 行動規範`

知らせてくれた人のことは、秘密にします。

### 守られなかったとき

リポジトリの持ち主（[@wakayamachannel](https://github.com/wakayamachannel)）が、何があったかを確かめてから決めます。
重さによって、次のようにします。

1. 注意する
2. 警告する
3. しばらく参加できなくする
4. ずっと参加できなくする

## English

PocketRoles uses the **[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)** as its code of conduct.
The full text (English) is on that page. Official 2.1 translations: [Japanese](https://www.contributor-covenant.org/ja/version/2/1/code_of_conduct/), [Simplified Chinese](https://www.contributor-covenant.org/zh-cn/version/2/1/code_of_conduct/); other languages are listed at <https://www.contributor-covenant.org/translations>.
Below is a short summary in our own words. Where the summary and the full text differ, the full text applies.
The source and licence are in the Attribution section at the end.

### Where it applies

GitHub (issues, pull requests), the official Discord "PocketRoles 役職部屋", support mail, and every place where people talk in the name of PocketRoles.

### What we all do

- Treat others with respect. Never look down on anyone for their age, gender, country, language, looks, game skill or anything else.
- Listen calmly to different opinions.
- When you make a mistake, apologize and fix it.
- Think about what is best for everyone, not only for yourself.

### What is not OK

- Insults, mocking, discrimination, harassment, or following someone around
- Sexual words or images
- Publishing someone else's personal information (real name, address, friend code and so on) without their permission
- Threats, or encouraging violence
- Other behavior that does not fit the place

### If something is wrong

If you think the code is not being followed, please tell us by e-mail.

- To: `pocketroles.report+help@gmail.com`
- Subject: `[PocketRoles] conduct`

We keep the reporter's identity private.

### What happens then

The owner of the repository ([@wakayamachannel](https://github.com/wakayamachannel)) checks what happened and then decides.
Depending on how serious it is:

1. A correction
2. A warning
3. A temporary ban from taking part
4. A permanent ban from taking part

## 简体中文

PocketRoles 采用 **[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)** 作为行为准则。
全文（英文）在该页面上。简体中文译文（2.1）：<https://www.contributor-covenant.org/zh-cn/version/2/1/code_of_conduct/>
下面是我们用自己的话写的简短摘要。摘要和全文不一致时，以全文为准。
出处和许可见最后的 Attribution。

### 适用范围

GitHub（Issue、Pull Request）、官方 Discord“PocketRoles 役職部屋”、支持邮件，以及所有以 PocketRoles 的名义与人交流的地方。

### 大家要做到的事

- 尊重他人。不因年龄、性别、国家、语言、外表、游戏水平等看不起别人。
- 冷静地听取不同的意见。
- 做错了就道歉并改正。
- 不只考虑自己，也考虑什么对大家最好。

### 不可以做的事

- 辱骂、嘲笑、歧视、骚扰、纠缠他人
- 带有性意味的言语或图片
- 未经本人同意公开他人的个人信息（真实姓名、住址、好友编号等）
- 威胁他人，或鼓动暴力
- 其他不适合该场合的行为

### 遇到问题时

如果你认为有人没有遵守本规范，请用邮件告诉我们。

- 收件地址：`pocketroles.report+help@gmail.com`
- 主题：`[PocketRoles] 行为准则`

我们会为报告者保密。

### 之后会怎样

仓库所有者（[@wakayamachannel](https://github.com/wakayamachannel)）会先确认发生了什么，再做决定。
根据严重程度：

1. 提醒
2. 警告
3. 暂时禁止参与
4. 永久禁止参与
