# 翻訳のしかた

[日本語](TRANSLATING.md) | [English](TRANSLATING.en.md) | [简体中文](TRANSLATING.zh-CN.md)

PocketRoles がゲームの中で出す文は、3 つの言葉のファイルにあります。
このページは、その翻訳を直す人のための決まりです。Pull Request の出し方は [CONTRIBUTING.md](../CONTRIBUTING.md) にあります。

## ファイル

| ファイル | 言葉 |
|---|---|
| `lang/ja.json` | 日本語（もとの文。ほかの 2 つはこれに合わせます） |
| `lang/zh-CN.json` | 简体中文 |
| `lang/en.json` | English |

- 文字コードは **UTF-8（BOM なし）** です。Windows のメモ帳なら、保存の時に「UTF-8」を選びます（「UTF-8 (BOM 付き)」ではありません）。VS Code などのエディターもおすすめです。
- GitHub の今の版（`main`）から直してかまいません。作者の手元に、まだ出していない新しい版があっても大丈夫です。取り込む時に作者が、あなたの直したところを 1 つずつ（キーごとに）新しい版にも入れます。

## ファイルの形

1 行に 1 つ、`"キー": "文"` が並んでいます。

```json
{
  "cmd.lang.set": "言語を {0} に設定しました。",
  "role.sheriff.name": "シェリフ",
  "kill.bite": "{0} に噛みつきました。{1:0.#}秒後に死亡します。"
}
```

- **キー**（左の `"cmd.lang.set"`）は変えません。消したり、足したりもしません。3 つのファイルは、同じキーを持っています。
- 直すのは **文**（右側）だけです。キーの意味は、3 つのファイルの同じキーを見比べると分かります。
- 文の中の `"` は `\"`、`\` は `\\` と書きます。改行は `\n` と書きます（本当の改行は入れません）。
- 最後の行のあとには `,` を付けません。コメント（`//`）は書けません。
- 行の順番は変えないでください（ほかの言葉のファイルと見比べやすくするためです）。

## そのまま残すもの

### 差し込み `{0}` `{1}`

- `{0}` や `{1:0.#}` のような `{ }` には、名前・数・役職名などが入ります。**そのまま残して**ください。中の数字や `:0.#` も変えません。
- 言葉の順番に合わせて、文の中で場所を動かすのは大丈夫です。例: `"{0} に噛みつきました。"` → `"You bit {0}."`
- 半角の `{ }` を使います。全角の `｛ ｝` はだめです。
- `{rules}` のような英語の名前の `{ }` も、コマンドの説明なので、そのまま残します。

### タグ `< >`

- `<color=#ff0000>…</color>` のような色のタグがあれば、同じように残します（今のファイルにはありません。色は MOD が付けます）。
- `<名前>` や `<役職>` のような `< >` は、コマンドの書き方の説明です。中の言葉は訳してかまいません。
- ただし `<b>` `<i>` `<u>` `<s>` `<size>` のような、ゲームが「書式」として読む言葉は `< >` の中に書かないでください。
  たとえば英語で秒を `<s>` と書くと、ゲームはそこから先を取り消し線にしてしまいます（`<seconds>` と書きます）。

### 改行 `\n`

- `\n` の数は、日本語の文と同じにします。1 行ずつ、別のチャットの行になります。

### 文の頭の空白やコンマ

- 頭が空白やコンマの文（例: `" キルCD{0:0.#}秒"`）は、ほかの文のうしろにつなげて使います。頭の空白やコンマは消さないでください（日本語の空白を英語で `, ` にするような、言葉に合わせた直しは大丈夫です）。

## チャットの長さ

MOD の文のほとんどは、ゲームのチャットで送ります。チャットは、1 通に入る文字の数が決まっています。

| 部屋 | 1 通に入る文字 |
|---|---|
| 登録した部屋（追加役職部屋） | 100 文字 |
| 登録オフの部屋（便利ホスト） | 86 文字（先頭に「[PocketRoles] 」が付くため） |

- 数えるのは文字の数です。漢字・かな・英字・数字・空白、どれも 1 文字です。`{0}` には名前などが入るので、10 文字くらいとして数えます。
- 長い文は、MOD が自動で何通かに分けて送ります。でも、通数が増えると読むのが大変になります。
  1 行（`\n` と `\n` の間）が 100 文字をこえると、行の途中で切れて、次の通に続きます。
- 次の文は **1 通に入れる決まり**です（入らないと、チェックがエラーにします）。
  - 登録オフの部屋の挨拶 `compat.welcome`（86 文字）
  - NG ワードの注意 `ng.warn`・`ng.warn.left`・`ng.warn.only`（10 文字の名前を入れて 86 文字）
  - そのほか（入室制限のお知らせなど）。全部の一覧は `tools/check-lang.ps1` のはじめのほうにあります。
- `/h` のヘルプや、部屋に入った時の挨拶（`welcome.*`）は、通数に上限があります。こえると、最後が「…」で切れます。
- 登録オフの部屋に出る文（`compat.*`・`help.compat.*`・`about.compat.*` など）では、ゲームのチャットで打てない文字が消えます。
  残るのは、文字・数字と `? ! , . ' : ; ( ) / \ % ^ & - = #`、`。` `、` `・` `ー` `「」` `『』` `【】` です（全角の `！（）：` なども半角になって残ります）。
  `→` `★` `♪` や絵文字は消えます。`< >` の記号も消えます。
  - `<` のすぐあとが b・i・u・s などで始まる言葉（`<seconds>` `<id>` `<user>` など）は、登録オフの部屋では中の言葉ごと消えます。こういう文では `<time>` のような別の言葉にします。
  - 「…」は「...」（3 文字）になります。1 通に入れる決まりの文は、「...」で数えます（チェックも同じに数えます）。

### 長さを確かめる

- Pull Request を出すと、自動のチェック（pr-checks）が数えます。直した文ごとに「前の通数 → 今の通数」と「いちばん長い行の文字数」を、チェックの Summary に出します。
- 画面に出る数字の説明は英語です: `messages` = 通数、`longest line` = いちばん長い行の文字数、`keys` = キーの数、`chat texts` = チャットの文の数、`changed` = 直した文。ファイルのチェック（check-files）の理由の文も英語です。
- 自分の PC で確かめる時は、リポジトリのフォルダで次のように打ちます（PowerShell 7 なら `pwsh tools/check-lang.ps1`）。
  `-BaseRef origin/main` を付けると、`main` から直した文だけの前と今を出します。

  ```
  powershell -NoProfile -ExecutionPolicy Bypass -File tools\check-lang.ps1 -BaseRef origin/main
  ```

  `origin/main` は、あなたのフォークの `main` です。本物のリポジトリを `upstream` として足した人は `-BaseRef upstream/main` にします
  （足し方: `git remote add upstream https://github.com/wakayamachannel/PocketRoles.git` のあと `git fetch upstream`）。

- `ERROR` は直す必要があります。`WARN` は、作者がいっしょに確かめます。

## ゲームの公式の言葉を使う

- ゲームにある言葉（インポスター、クルー、ベント、タスク、サボタージュ、会議、ゲームの役職の名前など）は、その言葉での **ゲームの公式の訳** にそろえます。
  - 例（中文）: Impostor は「伪装者」（「内鬼」ではありません）、Crewmate は「船员」。
- 公式の言葉の一覧は、まだリポジトリにありません（入れるかどうかを作者が決めているところです）。それまでは、上の例と、今の `zh-CN.json` の訳にそろえてください。作者も取り込む時に、手元で公式の言葉と比べます。
- MOD だけにある言葉（シェリフ・ジャッカルなど MOD の役職の名前）は、今のファイルの訳にそろえます。
  役職の名前はコマンド（`/cmd r 名前` など）でも使うので、変えたい時は Pull Request に理由を書いてください。作者がコードといっしょに確かめます。

## ゲームで試す

[README の「文言ファイル（編集可能）」](../README.md#文言ファイル編集可能)のとおりに、ホストの PC で試せます。

1. MOD を入れたゲームのコピー（`Among Us PocketRoles`）の `BepInEx\PocketRoles\lang\` にある同じ名前のファイルを、直したファイルで置きかえます（前のファイルは別の場所にコピーしておきます）。
2. ロビーでホストが `/lang reload` と打つか、ゲームを起動し直します。
3. ホストが `/lang zh`（中文）か `/lang en`（English）と打つと、ホストに出る文と部屋の言葉がその言葉になります。`/h` などで文を見ます。
   参加者にだけ届く文は、スマホなどでもう 1 人として部屋に入ると見られます。
4. 終わったら、ホストが `/lang ja` と打って部屋の言葉を戻します（`/lang zh` や `/lang en` で変えた部屋の言葉は、設定に保存されて次も残ります）。
   置きかえたファイルは、コピーしておいた前のファイルに戻すか、消します（消すと、次に起動した時に MOD に入っている文が書き出されます）。
   戻さないと、この PC ではあなたの試しの文が使われ続けます。
