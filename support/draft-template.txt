# ここまでがヘッダーです。To: は必須。Subject: は元の件名に「Re: 」を付けたもの。
# In-Reply-To: と References: は mail.txt の Message-Id / References をそのまま写します（相手のメールソフトで同じスレッドに並ぶため）。
# FAQ: と「#」で始まる行はメールに入りません（使った FAQ の id をユーザーが確認するためのメモ）。
# この下に空行を 1 行入れ、その次の行から本文（UTF-8）。本文が空のままだと下書きは作れません。
# reply-mail.cmd は Gmail の「下書き」に入れるだけで、送信はしません。送信はユーザーがブラウザの Gmail から押します
# （このツールから送ると、この PC（家）の IP アドレスがメールに入り、相手に見えてしまうためです）。
# 送信はブラウザの Gmail か、スマホの Gmail アプリからだけ。Outlook・Thunderbird・Windows の「メール」・iPhone の「メール」などの
# メールソフトにも下書きが出ますが、そこからは送らない（SMTP で送ることになり、家の IP アドレスが入るため）。
# 下書きを作ると末尾に「Drafted: 日時」が自動で追記され、同じファイルから二度は作れません。
